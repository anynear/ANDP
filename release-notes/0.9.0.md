## English

First public release of ANDP, the content-blind, replicated object store the anynear apps keep their encrypted data
in. The protocol version is v1; the library version starts at 0.9.0.

### Specification
- `spec/andp.md` describes protocol version v1 as the anynear network runs it, with the extensions watch, view and stream.
- Section 16 "Security considerations": what a relay sees, what it cannot do, what a faulty or malicious relay can do, the role of the network key, abuse.

### Libraries
- Kotlin Multiplatform client for Android, iOS, JVM and JS.
- Test vectors in `vectors/`, checked by the Kotlin client.

### Compatibility
- Paths `/andp/v1/…`, signing domains `andp/v1/…` and headers `ANDP-…` never change. An incompatible change will be `andp/v2` next to v1.
- The relay server and the protocol between relays are not part of this repository.
- Not independently audited.
